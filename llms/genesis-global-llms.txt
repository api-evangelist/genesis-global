# Genesis Global — The Genesis Application Platform

> Genesis Global provides an AI-native application development platform purpose-built for financial markets. The platform combines pre-built components and microservices with developer tools and documentation to help teams build, test, deploy, and operate high-performance, compliant applications faster.

Important notes:
- Target audience: developers, architects, and technical stakeholders in capital markets.
- Core pillars: component-driven framework, high-performance runtime, strong security/compliance, and integrated AI with guardrails.
- For hands-on access, use the Developer Portal (signup required).
